# Hijuelas Wayspot Scout Overlay

Userscript móvil para el mapa de Wayfarer que dibuja celdas S14/S17, referencias observadas y círculos empíricos de 22 metros. Se distribuye para uso personal con Violentmonkey.

## Instalación inicial o migración desde una versión anterior

1. En Firefox Android, abre Violentmonkey y elimina o desactiva cualquier instalación anterior llamada **Hijuelas Wayspot Scout Overlay**.
2. Abre el enlace [Instalar Hijuelas Wayspot Scout Overlay](https://raw.githubusercontent.com/atodomorris/wayfarer_tool_s2/main/hijuelas-wayspot-scout.user.js).
3. Violentmonkey mostrará el instalador. Pulsa **Instalar**; no copies ni pegues código.
4. En Wayfarer, recarga la pestaña del mapa y usa el botón **S2**.

## Actualizaciones posteriores

El script incluye `@updateURL` y `@downloadURL` apuntando a este mismo archivo. Para actualizar, abre Violentmonkey, toca el menú de Hijuelas Wayspot Scout Overlay y elige **Buscar actualizaciones**. Si hay una versión posterior, Violentmonkey la instalará desde este repositorio.

El script es una capa local de análisis: no envía nominaciones ni realiza solicitudes propias al mapa.
